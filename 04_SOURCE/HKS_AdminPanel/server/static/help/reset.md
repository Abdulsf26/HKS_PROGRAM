# Forgot the password

Two ways back in:

## You have the laptop
Run C:\HKS_PROGRAM\RESET_PASSWORD.bat as Administrator. It prints a new random password once. Log in with it, change it in Settings -> Users.

## You have a recovery code
On the login page choose "Forgot password?", enter a recovery code (printed once at install) + a new password. Each code works exactly once. Rate-limited like login, so guessing is hopeless.
