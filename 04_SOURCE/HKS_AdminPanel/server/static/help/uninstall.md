# Complete uninstall

- Run UNINSTALL_HKS.bat as Administrator, type YES to confirm.
- It stops tasks/services/processes, removes firewall rules and C:\HKS_PROGRAM, then VERIFIES each piece is gone.
- If the folder is locked, it is scheduled to vanish at the next reboot.
- Removal proof is written to C:\ProgramData\HKS-Audit (survives the uninstall).
- Optional: cleans HKS zip/parts files from your Downloads (asks first).
