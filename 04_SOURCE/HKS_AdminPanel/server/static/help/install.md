# Installing HKS

- Run INSTALL_HKS.bat as Administrator (right-click -> Run as administrator).
- Answer the questions. Default port is 8000. "Use HTTPS?" - N is the easy path on your own Wi-Fi.
- WRITE DOWN the 8 recovery codes it prints. They are shown once.
- Open the panel: http://localhost:8000 on the laptop.
- If anything fails, run HKS_DOCTOR.bat and read what it says - it names the exact problem.
