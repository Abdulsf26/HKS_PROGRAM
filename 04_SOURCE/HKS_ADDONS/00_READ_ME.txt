# Optional Add-ons

The add-on scripts in this directory install third-party software or configure Windows components. They are separate from the HKS core and may have independent prerequisites, licenses, resource requirements, network exposure, and removal steps.

Before running a script, inspect its contents and consult the upstream project's documentation. Run only add-ons you need, keep their credentials private, and restrict access to trusted networks. HKS does not guarantee that every optional add-on is compatible with every host.
