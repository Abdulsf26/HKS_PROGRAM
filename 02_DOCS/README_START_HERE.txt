# HKS PROGRAM — START HERE (Build 7.2.98)

## Install on Windows

1. Copy `HKS_PROGRAM_SETUP.exe` to the Windows computer you own or administer.
2. Run it and approve the Windows administrator prompt.
3. Choose **Install / Repair** and follow the setup wizard.
4. Use **Check status** or **Run diagnostics** in the setup GUI if needed.
5. Follow the wizard's printed address to open the dashboard.

Use HTTPS when browser microphone access is needed. A self-signed certificate warning may appear on first connection; verify the certificate fingerprint through a trusted channel before proceeding.

For updates, run the newer setup executable and select **Install / Repair**. For removal, choose **Uninstall** and review the data-backup choice.

See `SETUP_GUIDE.md` and `SECURITY.md` for details.
