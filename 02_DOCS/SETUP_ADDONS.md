# HKS Add-on Setup

1. Confirm that the host meets the selected add-on's current upstream requirements.
2. Read the corresponding `ADDON_*.bat` script before running it.
3. Run only on a computer you own or are authorized to administer. Elevate only when the script requires it.
4. Record the generated credentials and restrict firewall/network access.
5. Verify the service using its documented health endpoint and uninstall it using its own supported removal procedure.

Some add-ons require Docker Desktop, WSL, or third-party installers. Availability and behavior vary by Windows version and hardware; test each add-on independently before relying on it.
